# examples · 四份真实闲鱼文案

四份都按闲鱼卖家真实写法整理：标题带成色词，正文塞满「无拆修/无进水/支持验机/不议价」这类套装话术，最后跟一排标签。原价单独用 `--original` 传入，因为闲鱼正文里的「原价 4299」不一定是买家能看到的那个价。

| 文件 | 场景 | 原价 | 关键口径 |
|---|---|---|---|
| `case-01.txt` | 手机 · iPhone 13 128G，出差备用机 | 5999 | 「九成新」= 9成新（0.58），不是 95新；「无拆修、无进水、屏幕无划痕」都是否定句，不计瑕疵；「电池健康 85%」算电池衰减 -8% |
| `case-02.txt` | 家电 · 海尔 465L 冰箱，搬家急出 | 4299 | 正文同时写了「用了 4 年」和「2021 年买的」，以使用年限为准（4 年）；8成新 + 轻微磕碰 |
| `case-03.txt` | 相机 · 索尼 A7M3 单机身 | 12999 | 99新 + 无磕碰/无霉/无拆修 → 零瑕疵；快门数写在正文里，定价不含快门溢价（见边界） |
| `case-04.txt` | 服饰 · LV Neverfull 中号 | 12000 | 命中违禁词「正品保证假一赔十」（过度承诺类）；「五金无氧化、无磨损」不计瑕疵 |

跑法（`out/` 里的文件就是这样生成的，首行是生成命令，第二行是运行日期）：

```bash
python -m xianzhi --mock quote --file examples/case-01.txt --original 5999
```

## 看什么

- **否定句不算瑕疵**：闲鱼文案最爱写「无拆修、无进水、屏幕无划痕」，早期版本会把这些当成瑕疵，一份干净的手机被扣到瑕疵封顶 30%，建议价从 1271 掉到 890。现在 `rules.detect_flaws()` 会看关键词前面的否定前缀。
- **成色词不重叠**：`九成新` 和 `95新` 语义不同，前者按 9成新（0.58）算，后者按 95新（0.72）算，同一条描述差 24%。
- **到手价是真到手**：爱回收按回收价收，不是按挂价收，表里按 8 折估算；挂 942 在闲鱼是 942，到爱回收是 754，到红布林是 848（10% 抽成）。
- **违禁词只报真的**：`假一赔十` 这类过度承诺会被单列，并给出可替换写法。

## 已知口径边界

- 只认文本里出现的信息：没写原价就只能给方法，不给价；没写购入年份默认按 2 年。
- 成色、瑕疵都靠关键词，写得含糊（「挺好」「看图」）就按默认 95新、无瑕疵算，结果里会把系数标出来，方便自己改。
- 快门数、电池健康度这类参数只作为瑕疵/健康度参考，不进入定价公式，不能替代快门溢价与型号溢价。
- 价格库是区间模型，不等于当地成交价；同城、急出、包邮这些条件会明显影响实际成交。
